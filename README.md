# Corporate Business Intelligence & Power BI Dashboard Portfolio

## Project Overview
This repository serves as a professional portfolio showcasing end-to-end Business Intelligence (BI) solutions built using Power BI Desktop. The projects contained herein demonstrate advanced competencies in data extraction, structural data modeling, relational star schemas, DAX (Data Analysis Expressions) engineering, and user-centric dashboard design tailored for corporate decision-making.

## Core BI Capabilities Demonstrated
* Data Modeling & Architecture: Designing optimized Star schemas utilizing clear 1-to-Many relationships, active cross-filtering controls, and clean factual/dimensional table splits.
* DAX Engineering: Implementing custom explicit measures for business tracking, including Time Intelligence functions, conditional filters, and aggregate ratio calculations.
* Data Transformation (PQ / M): Utilizing Power Query to handle data type configuration, column splits, formatting, and structural schema validation prior to downstream loading.
* UI/UX & Executive Reporting: Structuring logical information hierarchies using clear, un-cluttered visual anchors and synchronized page slicing.

## Active Dashboards Summary

### 1. Marketing Campaign Performance & ROI Dashboard
* Business Objective: Analyze performance, conversion efficiency, and financial allocation across roughly 100,000 global marketing campaigns.
* Technical Highlights: Built dynamic relational bridges linking audience segments to regional target markets. Managed cost efficiency matrices using customized DAX funnel allocations.
* Key Visual Layouts: Funnel Conversion Tracking, Geospatial Acquisition Density Maps, and Regional Channel ROI Matrices.

### 2. Executive Classic Sales Dashboard
* Business Objective: Provide high-level stakeholders with visibility into historical sales performance, sales trend distribution, and total order volume metrics.
* Technical Highlights: Prioritized four core key performance indicators (Total Sales, Total Orders, Average Order Value, and Total Customers) using custom explicit DAX metrics and a highly constrained, professional color palette.
* Key Visual Layouts: Historical Sales Trend Line Charts, Country-Level Performance Bar Metrics, and Deal Size Distribution Donut Visuals.

### 3. Corporate Human Resources (HR) Data Dashboard
* Business Objective: Track organizational workforce metrics, employee distribution, and key corporate demographic trends.
* Technical Highlights: Handled complex dimensional filtering and data cleaning across transactional HR datasets to isolate active headcounts, attrition patterns, and department granularities.
* Key Visual Layouts: Workforce Demographic Breakdowns, Department Variance Matrices, and Active Employee Status Cards.

## Data Architecture Best Practices
To maintain clean operational standards, all projects adhere to the following architecture rules:
1. Explicit Measures Only: All calculations are built using explicitly written DAX scripts rather than implicit drag-and-drop values to preserve mathematical logic.
2. Schema Separation: Fact tables (containing transactional telemetry) are strictly separated from Dimension tables (containing attributes) to enforce optimal performance.
3. Optimized Layouts: Dashboards utilize professional corporate palettes with consistent alignment to maximize executive scanability.
